# 作文冒險 ✏️

一個給高年級小學生的遊戲化作文練習網頁，目標是準備**全民中文能力檢定（CWT）初等**寫作。

孩子用闖關、升級、集徽章的方式練習審題與分段，寫作規劃在網頁上完成、當場給經驗值回饋，稿紙只負責最後謄寫。

## 特色

- **21 個題目**：其中 15 題是 CWT 全民中檢初等 2013～2024 的歷屆真題，引導語照官方格式改寫。
- **難度分三區**：入門 / 進階 / 挑戰，全部開放不上鎖，從好取材的題目開始練。
- **先取名再出發**：第一次打開會幫自己取一個練習生的名字，升級時會叫你的名字。
- **三關制**：每題先做「作戰計畫」（審題＋動手寫大綱），再「謄寫完成」，最後對照稿紙做「自我檢查」。
- **審題挑戰**：從選項中挑出必寫重點、避開偏題陷阱，練審題判斷。選項每次都會重新洗牌，背不起來。
- **內容浮動經驗值**：打字時偵測五感詞、對話、比喻、狀聲詞，寫越具體、技巧越多，XP 越高；灌水和堆關鍵字不會加分。
- **可以重練**：同一題能「再挑戰一次」，分數取最高，寫得比上次好才會再加 XP。
- **內容自動保存**：計畫打到一半關掉也沒關係，下次打開接著寫。
- **藍圖帶得走**：一鍵複製成文字，或直接列印出來放在稿紙旁邊。
- **進度可以備份**：匯出成一個 JSON 檔，換手機或清快取之後匯回來就好。
- **主場景放大**：把最重要的一幕當場先寫細，練「單點放大」。
- **技能樹＋徽章＋等級**：對應中檢四大評分向度，進步看得見。
- **進度自動保存**：存在瀏覽器裡，下次打開接著玩。

## 怎麼使用

直接用瀏覽器打開 `index.html` 就能玩，不用安裝任何東西。

手機使用：把網頁放上網路後（見下），在手機瀏覽器打開，選「加入主畫面」。
已經設好圖示與全螢幕設定，開起來就是一個獨立的 App，沒有網址列。

## 放上網路（讓孩子/別人也能用）

這是純靜態網頁，任選一個免費平台。
**記得整個資料夾一起上傳**（`index.html` 以外還有 `manifest.webmanifest` 和三個 `icon-*.png`，主畫面圖示要靠它們）：

### 方法一：GitHub Pages
1. 在 GitHub 建一個新 repo，把這個資料夾的檔案上傳。
2. 進 repo 的 **Settings → Pages**。
3. Source 選 `main` branch、根目錄 `/`，按 Save。
4. 等一兩分鐘，網址會顯示在同一頁（形如 `https://你的帳號.github.io/repo名稱/`）。

### 方法二：Netlify 或 Cloudflare Pages（更快）
1. 註冊帳號，選「部署網站」。
2. 把整個資料夾直接拖進去，或連結 GitHub repo。
3. 自動部署完成，得到一個網址。

## 想繼續開發、加題目

用 Claude Code 打開這個資料夾，它會自動讀 `CLAUDE.md` 了解專案結構。
最常見的需求「加一個新作文題目」，在 `CLAUDE.md` 裡有完整的格式範例，跟 Claude Code 說「幫我加一個題目，題目是 XXX」即可。

## 技術

純 HTML + CSS + JavaScript，無框架、無相依套件、無建置流程。程式本體就是 `index.html` 一個檔案（另外幾個檔只是主畫面圖示）。進度用瀏覽器 localStorage 保存，也可以匯出成 JSON 備份。
